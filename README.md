# 大A祖训

高开之后，大概率要回吐 —— 用十年日K数据验证。

## 功能

- **7 个主流指数，多选**：上证指数、深圳成指、创业板指、科创50、沪深300、中证500、中证1000
- **拖动时间轴**自由选择统计的时间范围（也可直接输入起止日期）
- **自填高开幅度与回撤幅度**，改动后马上重算
- 统计口径（与页面内一致）：
  - 分母：区间内开盘价高于前收设定幅度的天数
  - 最低/收盘价比开盘低超回撤幅度：当日最低价或收盘价比开盘价低超过回撤幅度
  - 涨幅缩小一半以上：开盘缺口被回吐一半以上（最低价或收盘价跌破开盘价与前收的中点）
  - 收盘价比开盘价低：仅统计收盘价低于开盘价（任意幅度）

## 在线使用

GitHub Pages：https://wdr0214.github.io/da-a-zuxun/

## 数据

- 来源：东财日K（前复权）
- 覆盖：2015-01 至今（科创50 自 2019-12-31 起）
- 每周六更新当周日K数据

## 文件

- `index.html`：完整网页（数据已内嵌，单文件可直接打开）
- `data.json`：7 个指数的日K数据（[日期, 开, 高, 低, 收]）
- `template.html` / `build.py`：网页模板与构建脚本（`python3 build.py --fetch` 拉取最新数据并重新生成 `index.html`）
